# Banzai
MSFT Insights:Prédire les Mouvements d'Actions MSFT
Banzai construit en premier mieu un modèle de Machine Learning capable d’estimer la demande journalière de l'action Microsoft à partir d'indicateurs techniques et de données de marché. Grâce au modèle susmentionné et en utilisant un modèle économique classique qui calcule le prix d'équilibre en croisant l'offre et la demande. Pour ce faire, le modèle final nécessite la saisie de : l'offre actuelle, la demande et le prix de l'action à t-1 et la prime de risque. A la fin, on obtient le prix d'équilibre du titre MSFT et on pourra dès lors le comparer au cours boursier pour déterminer s'il est surévalué ou sousévalué.
Ce dépôt a été conçu comme un **projet portfolio**, adapté aux entretiens en :
- Data Science  
- Quantitative Analysis  
- Finance  
- Machine Learning

English



Banzai first builds a Machine Learning model capable of estimating the daily demand for Microsoft stock using technical indicators and market data. Leveraging this model, and combining it with a classical economic framework that computes the equilibrium price by intersecting supply and demand, the project provides a full analytical pipeline.

The final model requires the following user inputs: current supply, demand, the stock price at time t-1, and the risk premium. It then computes the equilibrium price of MSFT, which can be compared to the market price to assess whether the stock is overvalued or undervalued.

This repository is designed as a portfolio project, suitable for interviews in:

Data Science

Quantitative Analysis

Finance

Machine Learning
